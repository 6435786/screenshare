# שיתוף מסך

דף אחד לשיתוף מסך חד-פעמי, צפייה בלבד, בלי התקנה ובלי הרשמה.

## איך משתמשים
1. פותחים את הדף, לוחצים **התחל שיתוף** ובוחרים מסך / חלון / טאב.
2. מעתיקים את הקישור (או שולחים בוואטסאפ) למי שצריך לראות.
3. הצופה פותח את הקישור, מקליד את שמו ולוחץ **התחבר**.
4. אצל המשתף קופצת בקשה. **אשר** = הצופה רואה. **דחה** = לא.
5. **עצור שיתוף** (או סגירת הטאב, או כפתור העצירה של הדפדפן) מסיים הכול. הקישור מת.

## בטיחות
- קוד אקראי חדש בכל שיתוף. אין כתובת קבועה.
- הקישור עובד רק כל עוד טאב המשתף פתוח ומשתף.
- כל צופה דורש אישור ידני. אפשר לנתק כל צופה בנפרד.
- צפייה בלבד. אין שליטה מרחוק.
- הווידאו עובר מוצפן ישירות בין הדפדפנים (WebRTC). שרת התיווך רואה רק את הקמת החיבור.

## טכני
- קובץ יחיד: `index.html`. אין build.
- תיווך (signaling): שרת הענן הציבורי של PeerJS. הספרייה שמורה ב-`vendor/peerjs.min.js` (גרסה 1.5.4).
- STUN של גוגל + TURN חינמי של Open Relay (metered.ca) למקרים שחיבור ישיר נכשל.
- המשתף חייב דפדפן מחשב (Chrome / Edge). צופה יכול גם מטלפון.
